# Studovna elektromechanika

Výuková webová aplikace pro přípravu na zkoušku profesní kvalifikace **Elektromechanik/elektromechanička pro TZ (26-004-H)**.

## Obsah

- **Zkouška**: jak probíhá a jak se hodnotí, studijní plán
- **Učivo**: 11 lekcí podle hodnoticího standardu + NV 194/2022 Sb., každá s kontrolními otázkami
- **Kotel**: interaktivní řez kondenzačním plynovým kotlem, animace provozu, startovací sekvence, kvíz
- **Závady kotle**: diagnostické postupy krok za krokem
- **Praxe**: úlohy praktické zkoušky a vzor protokolu
- **Testy**: procvičování po tématech a simulace zkoušky
- **Ústní zkouška**: otázky se vzorovými odpověďmi
- **Slovníček**: pojmy a zkratky

Celá aplikace je jeden soubor `index.html` bez závislostí. Stačí ho otevřít v prohlížeči nebo zveřejnit přes GitHub Pages. Pokrok se ukládá do `localStorage` prohlížeče.

Testové otázky jsou cvičné, oficiální banka otázek není veřejná. Číselné hodnoty jsou typické; vždy platí aktuální normy a návody výrobců.
